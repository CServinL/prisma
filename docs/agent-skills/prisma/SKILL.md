# prisma — REST API + vault content conventions

Canonical source lives in the `prisma` repo at `docs/agent-skills/prisma/`;
this is a synced copy. If this skill looks stale, check that repo's copy
first rather than guessing — it's generated by reading the actual
route/model source, not by memory.

## What Prisma is

A local-first research-assistant server (FastAPI + SvelteKit): a flat-
Markdown vault (notes, sources, chats, streams) as the shared workspace,
Zotero as the bookmark layer, an embedded knowledge graph (Kùzu) and
ChromaDB for retrieval, and a tool-calling chat grounded in both.
`prisma serve` runs the API on `:8765` and the web UI on `:8766` by
default (both configurable).

## Two separate things this skill covers

1. **Calling the REST API** — see `references/rest-api.md` for the full
   endpoint catalog (grouped by area: notes/vault, streams, Zotero, graph,
   chat, sync, admin, search). Check `GET /health` first (unauthenticated);
   if `server.auth.mode` is `password`, every other route needs
   `Authorization: Bearer <token>` from `POST /auth/login`.
2. **Writing valid vault content** — see `references/vault-links.md` for
   exact syntax: `[[wikilink]]`, `![[transclusion]]`, `[[@citekey]]`
   citations, and the three interchangeable forms of a vault reference
   (`vault:/dir/name`, `dir--name`, bare `name`). Get this wrong and links
   render as a visible broken-link marker rather than silently failing —
   but still get it right the first time rather than relying on that.

## Fast rules that matter most

- **Chat tool names** (if generating/reasoning about chat transcripts or
  tool-calling prompts): `search_vault`, `graph_context`, `expand_node`,
  `god_nodes`, `surprising_connections`, `suggest_questions`, `read_source`,
  `recall`, `think`, `zotero_search`. All read-only — none of them write,
  delete, or reach outside the vault/Zotero read.
- **Link target format**: always prefer `vault:/dir/name` inside note bodies
  (the interchange form) — `dir--name` is the API/URL-path-segment form,
  not something to hand-write into a note.
- **Known limitation, don't paper over it**: a path component that itself
  contains `--` breaks the `dir--name` encoding's round-trip (it's not
  currently collision-safe). Not fixed yet — see the `prisma` repo's
  `TODO.md`. Don't invent a workaround inline; flag it if it's actually
  hit.
- **A Source's original file (PDF/EPUB/DOCX/etc.) is a "companion"**, not
  the node itself — the node is always the sibling `.md`. Don't assume a
  Source's content is inline in one file without checking for a companion.
