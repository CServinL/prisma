# Prisma REST API reference

Generated by reading the actual route decorators/response models in the
`prisma` repo (`prisma/server/*.py`), not from memory — if a route here
turns out wrong, that repo's source is authoritative, re-derive from it.

Base URL: `http://127.0.0.1:8765` by default (`prisma serve --port`).
`GET /health` is unauthenticated. If `server.auth.mode: password` is set,
every other route needs `Authorization: Bearer <token>` (from
`POST /auth/login`; refresh via `POST /auth/refresh`). WebSocket auth sends
`["bearer", "<jwt>"]` as a subprotocol instead of a header.

## Core (`app.py`, no prefix)

| Method | Path | Purpose |
|---|---|---|
| GET | `/health` | Liveness — unauthenticated |
| GET | `/status` | System status (subsystems, indexer progress, etc.) |
| GET | `/logs` | Recent log lines |
| POST | `/auth/login` | Password-mode login |
| POST | `/auth/refresh` | Refresh a session token |
| POST | `/reload` | Diff config on disk vs. loaded, reload only changed subsystems (what `prisma reload-config` wraps) |
| POST | `/reload/vault` / `/reload/zotero` / `/reload/indexer` / `/reload/chroma` / `/reload/chat` | Reload one subsystem individually |
| GET | `/models` | List available LLM models (from the configured provider) |
| POST | `/supervisor/restart/{name}` | Restart one supervised process (`api`/`web`/`chroma`/`kg`) |
| GET / PUT | `/chat/user-prompt` | Read/update the chat system-prompt override |
| POST | `/render` | Render raw markdown to HTML via the vault renderer (wikilinks/transclusions/citations resolved) |
| GET | `/home` | The vault's home/dashboard rendered node |
| GET | `/tree` | Full vault tree listing |
| POST | `/dirs` | Create a vault directory |
| POST | `/nodes/{slug}/move` | Move a vault node |
| POST | `/nodes/{slug}/rename` | Rename a vault node |
| POST | `/nodes/{slug}/taint` | Force re-extraction/re-index of one node |
| DELETE | `/nodes/{slug}` | Delete a vault node |
| GET | `/vault/assets/{asset_path}` | Serve a static/vault asset (extension allow-listed) |
| POST | `/maintenance/deduplicate` / GET `/maintenance/deduplicate/{job_id}` | Zotero dedup job (start / poll) |
| POST | `/review` / GET `/review/{job_id}` | Literature review generation job (start / poll) |

### Chat (`app.py`)

| Method | Path | Purpose |
|---|---|---|
| POST | `/chats` | Create a chat |
| GET | `/chats/{slug}` | Fetch a chat |
| POST | `/chat` | Send a message — runs the full tool loop synchronously, single-shot (not streamed) |
| POST | `/chats/{slug}/attachments/upload` | Upload a v3 media attachment |
| POST | `/chats/{slug}/attachments/promote` | Promote an attachment to a real vault Note |
| POST | `/chats/{slug}/turns/{index}/regenerate` | Regenerate a turn (prior attempt kept as an alternate) |
| POST | `/chats/{slug}/turns/{index}/pin` | Pin/unpin a turn into the chat's Excerpt |
| DELETE | `/chats/{slug}/messages/{index}` | Delete a turn |

## `/notes` (notes + sources)

| Method | Path | Purpose |
|---|---|---|
| GET | `/notes` | Vault listing |
| GET | `/notes/apa` | APA citation formatting for sources |
| GET | `/notes/{slug}` | Rendered node |
| GET | `/notes/{slug}/read` | Bounded excerpt read — `mode=summary\|section\|literal` + `query` — REST surface for the chat `READ_SOURCE` tool, never the whole file |
| GET | `/notes/{slug}/view` | Rendered HTML companion (asset-path-rewritten, iframe-embeddable) |
| POST | `/notes/{slug}/md` | Generate/refresh the `.md` body from an HTML/PDF companion |
| PATCH | `/notes/{slug}/type` | Change node type (`note` ↔ `source`) |
| GET | `/notes/{slug}/original` | Raw companion file bytes (any type in `COMPANION_EXTS`: pdf/html/htm/svg/epub/docx/tex/drawio/jpg/jpeg) |
| POST | `/notes` | Create a note |
| PUT | `/notes/{slug}` | Save a note's body |
| POST | `/notes/sources` | Create a Source manually (no Zotero) — bibliographic fields, auto-generates a citekey via `make_citekey()` if none given, 409 on citekey collision |
| PATCH | `/notes/{slug}/source` | Edit an existing Source's bibliographic fields (not `citekey` — see `vault-links.md`) |
| POST | `/notes/{slug}/companion` | Attach/replace a Source's companion file (multipart upload) — the manual counterpart to Zotero import's automatic PDF fetch |

## `/zotero`

| Method | Path | Purpose |
|---|---|---|
| GET | `/zotero/status` | Reachability/connectivity status |
| GET | `/zotero/collections` | List collections |
| GET | `/zotero/stats` | Library stats |
| POST | `/zotero/sync-pending` | Flush the offline write queue |
| GET | `/zotero/items` | List/search items — `collection`, `q` (server-side Zotero search, not client-side substring) |
| GET | `/zotero/items/relevance` | Same item set as `/items`, sorted by lightweight KG-entity-label-overlap scoring (PR #106) — no Zotero/stream content is ever indexed into Kùzu for this, it only scores text against labels already extracted |
| POST | `/zotero/import/{key}` | Import a Zotero item into the vault as a Source |
