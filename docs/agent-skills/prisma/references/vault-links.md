# Prisma vault link/citation syntax

Generated by reading `prisma/services/renderer.py` and
`prisma/storage/models/vault_models.py`'s `VaultRef` directly. If this
looks stale, re-derive from those two files rather than guessing.

## The three forms of a vault reference (`VaultRef`)

One parser (`VaultRef.parse`) handles all three, so pick whichever fits the
context — don't hand-convert between them yourself:

| Form | Example | Where it's used |
|---|---|---|
| `vault:/dir/name` | `vault:/papers/attention-is-all-you-need` | The interchange form — "Copy slug"'s output, and what you should write inside a `[[wikilink]]` |
| `dir--name` | `papers--attention-is-all-you-need` | The compound-slug encoding — this is what actually travels as a REST URL path segment, since a real `/` isn't URL-path-segment-safe. Don't hand-write this into note bodies. |
| bare `name` | `attention-is-all-you-need` | Plain slug, no folder — fine either place if the node is top-level |

**Known limitation** (tracked, not fixed): a path component that itself
contains `--` breaks `dir--name`'s round-trip decode (`archive/foo--bar.md`
→ `archive--foo--bar` → decodes back to `archive/foo/bar.md`, a different
path). Don't invent a workaround inline if you hit this — it's a real,
tracked gap (see the `prisma` repo's `TODO.md`), not something to silently
route around.

## Wikilinks — `[[target]]` or `[[target#Section]]`

```
See [[vault:/papers/attention-is-all-you-need]] for the original transformer paper.
See [[transformer-architecture#Positional Encoding]] for a specific section.
```

- Renders as `<a class="wikilink" href="#note:{slug}{anchor}">` if the
  target resolves (`vault.slug_exists()`), else a visible
  `<span class="broken-wikilink">⚠ [[target]]</span>` — broken links fail
  loudly in the rendered output, not silently.
- The visible label is always whatever you typed, even when the target
  resolves — there's no separate `[[target|label]]` display-text syntax.
- `#Section` matches a markdown heading by exact text (case-insensitive)
  within the target document.

## Transclusions — `![[target]]` or `![[target#Section]]`

Same target syntax as a wikilink, but embeds the target's rendered content
inline (recursively, up to depth 5) instead of linking to it:

```
![[vault:/notes/shared-definitions#Key Terms]]
```

Renders as `<div class="transclusion" data-slug="{slug}">...</div>`
wrapping the resolved content, or
`<span class="broken-transclusion">⚠ ![[target]] not found</span>` if the
target doesn't exist.

## Citations — `[[@citekey]]`

References a Source by its Zotero `citekey` (from frontmatter), not by
slug:

```
This result was later contested [[@smith2024attention]].
```

Renders as `<a class="citation" href="#source:{slug}" data-citekey="...">`
if a Source with that `citekey` exists anywhere in the vault, else
`<span class="broken-citation">⚠ @citekey</span>`.

## Node frontmatter basics

Every vault node is a `.md` file with YAML frontmatter. The minimum a
freshly created Note has: `type: note`, `title: ...`. Sources add
bibliographic fields (author, year, citekey, etc.) populated from Zotero on
import. Don't assume a Source's actual content is fully inline in that one
`.md` file, though — see "Companions," next.

## Companions — a Source's original file isn't the node

A Source's original file (PDF, HTML, EPUB, DOCX, TeX, drawio, JPG/JPEG) is
stored as a sibling **companion** file (`<slug>.pdf` next to `<slug>.md`),
never the node itself — the node is always the `.md`. The `.md` body is
either hand-written or converted from the companion
(`VaultService.ensure_md_format()`, via `docu-craft`). If you need the
original bytes rather than the derived markdown, that's
`GET /notes/{slug}/original` (see `rest-api.md`), not the node's own
content.

Image companions (jpg/jpeg today; png/gif/webp not even recognized yet)
have **no text extraction** — there's no vision/OCR step, so an image
companion's `.md` body stays whatever was hand-written, not a caption
derived from the image. Don't assume an image's content is searchable or
summarizable from vault text alone.
